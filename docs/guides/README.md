# User guides

Plain-language guides for practice staff. [The guide for line managers](manager.md) covers signing in, deciding requests, recording leave and sickness, team balances, your starters' and leavers' jobs, your team's checks and your team's training. [The guide for HR administrators](hr-administrator.md) covers everything else: setting people up, starters and leavers, checks, training, policies, reminders, leave rules, year end, payroll and logins.

For what every admin setting means in detail, see the technical reference in [docs/admin/](../admin/README.md).
