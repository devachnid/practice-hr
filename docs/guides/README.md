# User guides

Plain-language guides for practice staff. [The guide for line managers](manager.md) covers signing in, deciding requests, recording leave and sickness, and team balances. [The guide for HR administrators](hr-administrator.md) covers everything else: setting people up, leave rules, year end, payroll and logins.

For what every admin setting means in detail, see the technical reference in [docs/admin/](../admin/README.md).
